# Privacy Policy for Image Viewer

Last updated: August 28, 2026

Image Viewer is committed to protecting your privacy.

## Data Collection & Storage
- **Image Viewer does not collect, track, or transmit any personal data, browsing history, or analytics.**
- User preferences (such as opacity level, keyboard shortcut settings, fit mode, and zoom sensitivity) are saved strictly locally on your device using Chrome's local storage API (`chrome.storage.local`).
- No data is ever transmitted to external servers, cloud databases, or third parties.

## Third-Party Services
Image Viewer does not integrate or communicate with any third-party services, SDKs, external APIs, or tracking cookies.

## Permissions Usage
- `contextMenus`: Used solely to provide the right-click "Open with Image Viewer" action on images.
- `activeTab`: Used to display the viewer overlay only on the current tab when explicitly requested by the user.
- `scripting`: Used to dynamically inject the viewer script into the active tab upon clicking the context menu option.
- `storage`: Used solely to preserve user UI settings and preferences locally.

## Changes to This Policy
If changes are made to this policy, updates will be published directly to this document within the official extension repository.
